## Desired Functionality:
1. Connect instagram account
2. access saved posts in a convenient panel where I can filter by account nickname, where I can (potentially) delete posts in batches and the changes would be reflected on instagram account as well. 
3. extract metadata about posts (without downloading video. video download should only happen on demand. for example when user clicks on post and presses play. this is a complicated part because I want to minimize storage cost). Note that I want the user to have a convenient video player because web version of instagram has a terrible video player. Research the https://apify.com/apify/instagram-scraper . I am okay to use it if this is the best option. it is paid however so maybe there is another way to achieve the task. If not then users would have to pass their API key. This will be an open source project so that is why I cannot incure any costs. 
4. Build a knowledge graph of the posts based on the post metadata (not the content itself). I want to have an AI report about my saved posts, patterns, etc. I want to be able to ask a question like 'list all the posts that are related to claude code'. In response to this question, the semantic search should happen and the videos that correspond to the request should appear in the UI. This is helpful if many saved posts exist so it is easier to navigate and see the related posts.
5. Build an AI summary of every post (lazy. only when the user clicks on it and clicks the button 'analyze'). AI should analyze the metadata about the post along with extracted frames and transcribed audio. Research repositories https://github.com/taoufik123-collab/claude-watch and https://github.com/bradautomates/claude-video . They already describe the functionality related to putting videos in the format that AI can understand. I know that gemini can understand videos directly so I can allow users to select which processing method to chose. users will be obligated to put api key for whisper/openai and optionally for gemini if they want to use it for video understanding. As a result, I want to display a report that a user can further process with AI of the choice. I do not want to embed chat functionality in my app yet.
